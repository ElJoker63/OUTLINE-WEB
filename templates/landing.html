Engineered for Security, Speed & Simplicity

Everything you need to orchestrate and administer your Outline VPN nodes in one unified, reactive dashboard.

ShadowSocks AEAD Security

Harnesses state-of-the-art encryption ciphers (ChaCha20-Poly1305 and AES-256-GCM) designed to resist deep packet inspection and network censorship.

Zero-Reload AJAX Architecture

Create, rename, set personal limits, and delete access keys seamlessly without refreshing the webpage. Instant optimistic updates with spring animations.

Visual Bandwidth Distribution

Integrated Chart.js analytics that break down monthly data transfer across all active clients in vivid neon gauges with live polling support.

Instant Key Suspension (Pause)

Temporarily freeze traffic for any connected device without deleting its key or regenerating credentials. Resume access with one tap.

1-Click Client Invite Pages

Generate shareable client portals (/invite/{key_id}) featuring 1-click outline:// connect triggers, QR codes, and official app store links.

Multi-Node Cluster Switcher

Store multiple Outline server profiles and switch between different geographic regions (Tokyo, Frankfurt, Miami) straight from the navigation bar.

How It Works

Three simple steps to deploy and control your private VPN network.

01

Deploy Outline Server

Run the official installation script on any Linux cloud VPS (Ubuntu, Debian, CentOS). It configures the Outline Docker container automatically.

02

Paste Credentials

Copy the resulting JSON snippet containing your secret apiUrl and certSha256 hash, and paste it into the secure sign-in portal.

03

Manage & Share

Create individual device keys, assign monthly data transfer quotas, inspect live traffic stats, and invite users via QR codes.
